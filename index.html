Multiplayer for every game.
One script. Zero servers.

FrostByte is a tiny JavaScript library that turns any HTML/CSS/JS game into a live multiplayer experience. Drop in play.js, call quickMatch() — and your game searches for players on your network, in your country, then worldwide. No backend. No keys. No bills.

Why FrostByte

Everything you need for real-time multiplayer — and nothing you don't. No accounts, no servers, no credit card. Just WebRTC doing what it does best.

🆓

Free. Actually free.

Game data travels peer-to-peer over WebRTC. The free public broker only does introductions. There is no usage bill — ever. Host the docs on GitHub Pages like this one.

⚡

One script, live server

Add <script src="play.js"> and your page is the live server. Works from GitHub Pages, itch.io, Neocities, or a plain file preview — anywhere browsers run.

🌍

Smart matchmaking

quickMatch() searches players on the same network first (same Wi-Fi = zero lag), then your country, then worldwide. You always find someone.

🕹

Game-ready API

host(), join(code), send(), broadcast(), join/leave events, auto heartbeats, dead-player pruning. Built for games, not for reading RFCs.

🔗

Room codes

Want to play with a friend in private? host() mints a 4-character code like K7XF. Send it to anyone on Earth — they're in with one join() call.

🔁

Host relays for free

Star topology: the room host relays traffic between players, so 2–8 player games work without a server, and guest→guest messages just work via send(data, toId).

🧩

Templates included

Copy-paste starting points: a full multiplayer Pong, a lobby chat, and a minimal starter. Fork one and rename the sprites — done.

🛠

Open & hackable

MIT licensed, single file, zero dependencies. Read the source, self-host your own signaling broker with peerConfig, or fork the whole thing on GitHub.

Live in three lines

How to connect your game using JavaScript — the entire ceremony, from cold page to synced multiplayer.

STEP 1

Drop in the script

One tag before your game code. That's the whole install — the WebRTC engine self-loads from CDN.

your-game.html
<script src="https://gefrus112.github.io/FrostByte/play.js"></script>
STEP 2

Create the game handle

The namespace keeps your rooms separate from every other game on the network.

game.js
const game = new Play({
  game: 'my-awesome-game',
  playerName: 'ace'
});
STEP 3

Connect & sync

Auto-match, or host and share a code. Then broadcast state — both sides get it in milliseconds.

game.js
await game.quickMatch();     // or host() / join('K7XF')

game.onData = (d, from) => movePaddle(d);
game.broadcast({ paddleY: 240 });
