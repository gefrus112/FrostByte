Generate keys for your FrostByte integration, allow-list the sites that may use them, and see the exact URL of every page the API is being used from. When a game connects with apiKey, FrostByte validates the key, checks the site allow-list, and records where it was used — right here.

Name the key and list the site URLs it may be used on — one per line. Use * to allow every site.

How it works with zero servers: keys live in this browser's localStorage — FrostByte is fully serverless, so there is no database to breach. Validation and the site allow-list are enforced inside play.js itself when your game connects with apiKey, and every successful connect is logged with the page URL it came from.
